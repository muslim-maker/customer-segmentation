# Анализ сегментации клиентов 
📌 Обзор проекта

Этот проект анализирует поведение клиентов и сегментирует пользователей на основе их вклада в доход.

🧩 Набор данных

Открытый набор данных по электронной коммерции Бразилии от Olist

⚙️ Используемые инструменты
SQL
Excel (ВПР, сводные таблицы)
🔍 Методология
Агрегирование показателей клиентов с помощью SQL
Расчет общей выручки, количества заказов и средний чек на пользователя
Сегментация клиентов в Excel
Создание сводных таблиц и визуализаций
📊 Результаты
1. Основная масса клиентов — низкоценный сегмент
**89% клиентов** относятся к сегменту **Low**. Это массовая аудитория с небольшими покупками.

### 💡 2. Medium — важная зона роста
Сегмент **Medium** занимает только **9.1% базы**, но приносит **25% выручки**. Этих клиентов проще перевести в High.

### 💡 3. High и VIP — самые ценные клиенты
Всего **2% клиентов** формируют почти **16% общей выручки**. Их удержание особенно важно.

💡 Ключевые выводы
Выручка сильно сконцентрирована
Большинство пользователей имеют низкую ценность
Бизнесу следует сосредоточиться на удержании высокоценных клиентов
