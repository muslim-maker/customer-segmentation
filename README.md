# Анализ сегментации клиентов 
📌 Обзор проекта

Этот проект анализирует поведение клиентов и сегментирует пользователей на основе их вклада в доход.

🧩 Набор данных

Набор данных Olist по электронной коммерции

⚙️ Используемые инструменты
SQL
Excel (VLOOKUP / XLOOKUP, сводные таблицы)
🔍 Методология
Агрегирование показателей клиентов с помощью SQL
Расчет общей выручки и количества заказов на пользователя
Сегментация клиентов в Excel
Создание сводных таблиц и визуализаций
📊 Результаты
Выявление высокоценных (VIP) клиентов
Анализ распределения выручки по сегментам
Обнаружено, что небольшая группа пользователей генерирует большую часть выручки
📈 Визуализация

💡 Ключевые выводы
Выручка сильно сконцентрирована
Большинство пользователей имеют низкую ценность
Бизнесу следует сосредоточиться на удержании высокоценных клиентов
🚀 Перспективы улучшения
RFM-сегментация
Комбинация когорты и сегментации
Прогностическое моделирование
